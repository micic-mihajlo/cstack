# Steer with principle names

Spudex mirrors the 21 Spudex principles as internal reference leaves under [references/principles/](../../references/principles).

Invoke a principle through the single installed front door as `$spudex principle-<slug>`, or use its plain-language name to redirect the work. These commands route to internal reference leaves; they are not 21 separately installed Codex skills.

## Steering in practice

- `$spudex principle-subtract-before-you-add`
- `$spudex principle-prove-it-works`
- `$spudex principle-separate-before-serializing-shared-state`

Each phrase works only if it changes a real decision.
